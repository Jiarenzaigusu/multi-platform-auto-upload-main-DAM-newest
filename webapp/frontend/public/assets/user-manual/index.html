日常发布操作速查

适用于已经安装并配对 Windows 助手的用户。首次使用请先完成第 1 章，再按本页操作。

1. 打开发布台和 Windows 助手，确认网页显示代理在线。

2. 进入“发布工作台”或“批量发布任务”，选择平台、内容类型和店铺，点击“校验 Cookie”；失败时先重新登录。

3. 选择素材并填写内容。核对图片顺序、封面比例、标题、商品 ID、声明和定时；批量素材必须在执行电脑上可读取。

4. 首次使用或更换关键配置时，先创建流程验证任务。在“任务与日志”确认验证完成，检查 Edge 中的素材和字段。

5. 准备正式提交时，取消勾选“流程验证”，重新创建正式发布任务。批量任务也要明确选择正式发布。

6. 保持助手和 Edge 运行，查看任务结果。平台接收后，再到平台后台核对审核、定时和上线状态。

提交前再检查一次

平台、店铺和素材是否正是本次要发布的内容。

工作台是否沿用了上次的字段或发布时间。定时至少比提交时晚 2 小时。

同一内容是否已经提交，历史任务是否还有“结果待核对”。

看到异常时

失败：先查看任务错误，再修正原因。批次部分失败见第 7 章；修改 Excel 后需重新上传，重执行不会读取新表格。

结果待核对 先查平台后台。确认是否已经提交之前，不要重复创建相同内容的任务。

流程验证 验证会上传并填写页面，但不执行最终发布。验证任务完成后，还需要另建正式发布任务。

1 首次使用 登录发布台

准备一台安装 Microsoft Edge 的 Windows 电脑、你的系统账号，以及目标平台的登录方式。网页、Windows 助手和 Edge 分别负责填写任务、执行任务和完成平台登录。

已有账号

打开发布台，在“登录”页输入用户名和密码。管理员使用已有管理员账号登录，无需重新注册。

没有账号

1. 切换到“注册”。填写用户名，显示名称可按需要填写。

2. 填写“账户展示品牌名”，使用公司在系统中登记的品牌名。此字段用于账户资料；数据品牌权限由管理员设置。

3. 设置至少 10 个字符的密码，并在“确认密码”中再次输入。

4. 点击“注册并进入发布台”。注册成功后默认获得操作员权限。

1 首次使用 配对并检查连接

1. 在网页“Windows 助手”窗口点击“生成一次性配对码”；已有旧码时可重新生成。配对码 5 分钟内有效。

2. 在本地助手输入发布台地址和配对码，点击“完成配对”。地址使用网页提示的发布台地址；不要填业务子页面路径。

3. 看到助手显示“已连接”，返回网页，确认顶部显示绿色“代理在线”或“本地代理在线”。

4. 配对后助手会在当前 Windows 用户登录时自动启动。以后日常使用先检查在线状态即可。

图 4 左图填写地址和配对码 右图为配对成功状态

连接不成功 先检查助手是否运行、地址是否正确、配对码是否过期，再生成新码重试。详见第 8 章。

重新配对 每个系统用户同时只允许连接一台助手。重新配对会撤销旧设备令牌；换电脑后还需要重新登录各平台。

2 登录目标平台账号

系统账号用于进入发布台；平台账号用于登录天猫、京东、小红书或抖音。完成系统登录后，仍需在本机 Edge 中登录目标平台。

1. 进入“发布工作台”，选择目标平台和发布类型。

2. 填写或选择“店铺”标识。它用于区分本机保存的平台账号，例如 店铺A 或 shop_a，不要求与真实店铺名相同。允许中文、字母、数字、下划线和连字符，长度 1–64；同一账号保持使用同一标识。

3. 点击“登录 / 重新登录”。本地助手会打开 Edge；若窗口未显示在前台，点击 Windows 任务栏中闪烁的 Edge 图标。

4. 在 Edge 中完成扫码、密码、短信或验证码验证。请确认登录的是目标平台账号。

5. 等登录任务结束，再回到发布台点击“校验 Cookie”。Cookie 是本机保存的登录凭据；校验用于检查登录是否仍有效。

图 5 先选平台和店铺 再登录并校验 Cookie

完成标志 Cookie 校验通过。随后先做一条流程验证任务，确认素材和字段可以正常填写。

校验失败 先重新登录并完成平台验证，再校验。登录、人工验证和平台 Cookie 均在执行任务的用户电脑上处理。

3 发布一条视频

入口为“发布工作台”。开始前确认助手在线、目标店铺 Cookie 校验通过，并准备好可读取的视频文件。

1. 选择平台、“视频发布”和店铺。切换后再次确认目标账号。

2. 点击“选择视频文件”，或通过 DAM 选择视频。支持 MP4、MOV、MKV、M4V、AVI、WebM。

3. 需要自定义封面时选择封面图片。天猫有自定义封面时必须明确选择“原始”“3:4”或“1:1”；无自定义封面时无需设置比例。京东封面只支持 JPG/PNG，最大 5 MiB。

4. 填写标题，以及当前平台显示的文案、标签、商品 ID、话题、音乐和创作者声明。京东视频没有独立正文，不要在文案字段填内容。平台限制见第 4 章。

5. 需要定时时选择发布时间，至少比当前时间晚 2 小时。不需要定时则留空。

6. 首次使用或修改了平台、封面、字段时，勾选“流程验证”，点击“创建流程验证任务”。

7. 到“任务与日志”查看任务消息和 Edge 页面。确认填写正确，并看到“流程验证已完成，未提交发布”后，回到工作台复核配置。

8. 取消勾选“流程验证”，点击“创建正式发布任务”。执行期间保持 Edge 和助手运行，结束后查看结果。

如何判断完成

流程验证的“已完成”只表示测试结束。正式任务提示“平台已确认接收发布”表示平台接收了提交；是否审核通过或按时上线，还需查看平台后台。

素材与草稿

浏览器只保留不超过 100 MiB 的视频草稿副本。更大的视频仍可发布，但刷新页面后需重新选择。后端默认单请求上限为 20 GiB，实际还受服务器配置和平台页面限制。

再次发布前 工作台可能保留上次的配置。再次提交前逐项检查素材、店铺和发布时间，避免沿用旧配置。

3 发布一条图文

图文沿用视频的账号登录、流程验证和正式发布步骤；素材准备方式如下。

1. 在“发布工作台”选择平台、“图文发布”和店铺。

2. 点击“选择图片文件”按顺序选择，或点击“选择图片文件夹”。文件夹模式只读取第一层支持格式图片，按文件名排序。

3. 检查页面图片清单。用“上移”“下移”“移除”调整顺序；确认第一张及后续图片符合内容安排。

4. 天猫图文必须选择图片比例：“原始”“3:4”或“1:1”。原始比例跳过裁剪；另两种比例会进入裁剪流程。

5. 填写标题和当前平台支持的正文及其他字段。先创建流程验证任务，检查图片顺序和裁剪结果，再创建正式发布任务。

1. 进入目标文件夹，选择所需素材；需要换目录时使用“返回上一级”，需要刷新时使用“重新加载”。

2. 确认已选素材，点击窗口底部“使用所选素材”。等待导入完成，再返回工作台检查素材清单。

图 7 浏览文件夹 选中素材后点击使用所选素材

无法打开 提示素材库未配置或没有可访问目录时，联系管理员检查配置和权限。

4 平台字段与填写规则

本页列出系统的主要校验要求。标题长度按字符计算，标点、数字和英文也会占用长度；平台页面如有额外校验，按页面提示处理。

平台

标题和正文

支持的附加字段

天猫视频和图文

标题 1–30 字符；文案与标签合计最多 1000 字符；内容标签最多 4 个。

最多 6 个商品 ID；活动话题、音乐、品牌标签、定时和创作者声明。

京东视频

标题 5–27 字符；没有独立正文。

最多 10 个商品 ID；参与话题、京东三级标签、定时、创作者声明和自主原创。

京东图文

标题 5–20 字符；正文最多 1001 字符。

同京东视频；不支持自由文本内容标签和音乐。

小红书视频和图文

标题 1–20 字符；正文最多 1000 字符。

内容标签、可选视频封面、定时；不支持商品 ID、活动话题和音乐。

抖音视频和图文

标题 1–30 字符；正文最多 1000 字符。

内容标签、可选视频封面、定时；不支持商品 ID、参与话题和音乐。

商品 ID 和定时

商品 ID 只填纯数字。多个 ID 可用逗号、中文逗号、空格或换行分隔，系统会去重并保留原顺序。

定时支持 YYYY-MM-DD HH:MM 或 YYYY年MM月DD日 HH点MM分。提交时必须至少提前 2 小时；已经接近执行时间的批量任务也要重新检查。

声明和京东标签

天猫和京东选择与真实内容一致的创作者声明，使用页面或模板提供的选项。小红书和抖音当前无需填写该字段。京东“自主原创”仅在账号已开通且内容符合要求时勾选；Excel 建议明确填“是”或“否”。

京东三级标签：页面按选项选择；Excel 填完整层级路径，各级用 / 分隔，多条路径用分号或换行分隔。兴趣标签最多 3 个、体裁最多 1 个，实际可用路径以当前模板和页面选项为准。自由文本内容标签用中英文逗号分隔；不要混用两种标签。

5 用 Excel 批量创建任务

入口为“批量发布任务”。每次选择一个平台、内容类型和店铺，再下载对应模板；单次最多 200 行内容。

1. 确认本地助手在线，选择平台、视频或图文和店铺，并校验 Cookie。

2. 点击“下载 Excel 模板”。保留当前模板的表头，不混用其他平台或内容类型的模板。

3. 每行填写一条内容。把视频、封面或图片文件夹路径填写为执行任务的 Windows 电脑上的绝对路径。

4. 检查必填内容、标题长度、图片数量、声明、定时和素材路径。先用少量内容测试；首次建议勾选“流程验证”。

5. 保存并关闭 Excel/WPS 文件，再上传。点击对应的创建任务按钮。

6. 若提示校验错误，按页面显示的 Excel 行号和字段修改全部错误，然后重新上传。任一行校验错误都会使整批不创建。

7. 看到“已创建 N 条任务”后，进入“任务与日志”查看。任务可按“Excel 第 N 行”追踪；单条执行失败不会阻止同批后续任务。

本机路径示例

视频路径 D:\发布素材\夏季上新\video01.mp4

自定义封面 D:\发布素材\夏季上新\cover01.jpg

图片文件夹 D:\发布素材\夏季上新\图文01

路径指向配对助手所在的电脑。填写前在这台电脑的文件资源管理器中打开文件或文件夹，确认存在且可读取。不要填相对路径、网页链接、云端存储路径或另一台电脑的盘符。

创建后保持素材可用

批量表只引用本机文件。任务执行前及执行期间不要移动、重命名或删除这些文件，也不要关闭助手或 Edge。

重传前检查 整表校验失败时可修正后重传。已经创建任务后，不要直接把整表再次上传；先核对每条任务，防止重复发布。

5 使用批量路径导入工具

Windows 助手提供“批量发布路径导入工具”，可为天猫或京东的视频、图文模板填写本机素材路径。无需安装 Microsoft Excel；生成后可用 Excel 或 WPS 补充内容。

先导入路径 再填文案 工具会清空输出表的数据区，再填写路径。必须使用空白模板；已填好的标题、文案和其他字段不会保留。先备份已有表格。

1. 在发布台选择天猫或京东及内容类型，下载对应的空白 Excel 模板。

2. 打开 Windows 助手，点击“批量发布路径导入工具”，选择刚下载的模板。

3. 视频：选择视频所在的总文件夹；工具会递归读取子文件夹。需要封面时再选择封面文件夹，按同名文件匹配。

4. 图文：选择总文件夹，其直接子文件夹分别作为一条图文的图片文件夹。不要直接选择单条图文的文件夹。

5. 选择一个新的输出文件名保存，不能覆盖模板。单次最多 200 条，超出时拆分文件夹后再处理。

6. 打开生成的表格，核对每行路径和封面匹配，补齐标题、文案、声明等字段，然后按第 5 章上传并测试。

视频与封面的命名示例

视频 D:\发布素材\视频\01_商品展示.mp4

封面 D:\发布素材\封面\01_商品展示.jpg

视频与封面使用相同主文件名、不同扩展名。避免不同子文件夹出现同名素材；出现同名文件时必须人工确认匹配结果。

工具完成后仍需检查

视频使用 MP4、MOV、MKV、M4V、AVI 或 WebM。工具可能收集 WMV/FLV，但发布端不支持；从输出表移除或先转换格式。

工具匹配封面不代表格式、大小或比例合格，按第 3、4 章核对。

结果待核对的处理顺序

1. 记录任务的平台、店铺、标题、创建时间和素材。

2. 用同一平台账号进入后台，按对应内容和时间查找，确认是否已提交、待审核、定时或已发布。

3. 找到内容后，按后台实际状态处理，避免重复创建。未找到时继续结合任务日志核对；确认没有提交后再决定重建。

取消和删除

排队任务可以取消。执行中的任务取消后先进入“正在中断”；如果平台提交动作已发生而回传中断，可能转为“结果待核对”。取消不等于撤回已经发布的平台内容。

删除终态任务前先保留需要的错误信息。删除只移除任务记录和独立日志，不删除平台内容、Cookie 或平台总日志。顶部“需处理”同时包含失败和结果待核对，不能只看统计数字判断结果。

7 处理批次中部分失败的任务

批次中一条任务失败，不会阻止后续任务执行。先查看失败条目的 Excel 行号、错误消息和日志，再决定使用重执行还是重新创建任务。

原有内容无需修改时

1. 在“任务与日志”找到对应批次，先核对成功、失败和结果待核对的条目。

2. 修正错误原因，例如重新登录并校验 Cookie、恢复网络，或将素材恢复到原路径。

3. 点击批次的“重执行失败项”，或详情中的“一键重新执行失败任务”，确认后查看新建任务。该操作只重建失败条目。

4. 查看新任务结果。若原任务是流程验证，重执行后仍然是流程验证；要正式发布必须另建正式任务。

需要修改标题 文案 路径或定时时

修改 Excel 后，重执行按钮仍使用原任务保存的参数，不会读取修改后的表格。请把需要修改且确认未提交的内容整理成新表，复核后重新上传创建任务。

避免整批重复提交 已成功的条目不要再次放入新表。使用行号与标题逐条核对需要重建的内容，保留原批次以便追踪。

结果待核对先查平台

“结果待核对”不属于失败重执行范围。用同一平台账号到后台确认是否已经提交；确认前不要重建。取消任务也不等于撤回平台内容。

需要管理员协助 提供批次或任务编号、Excel 行号、平台、店铺和错误消息，便于定位；不要发送密码、API Key 或完整 Cookie。

1. 等待正在执行的发布任务结束。

2. 双击“MPAU 本地执行助手”，检查更新；有新版本时点击“安装新版本”。

换电脑和账号权限

本机助手数据位置

%LOCALAPPDATA%\MPAU-Agent\

device.json

connection.json # DPAPI 保护的设备令牌

users\<user_uuid>\cookies\{tmall,jd}\

users\<user_uuid>\uploads\<job_id>\

users\<user_uuid>\job-logs\

users\<user_uuid>\platform-logs\

平台凭据按用户和平台保存在本机数据目录，实际目录随平台配置变化。设备令牌使用 Windows DPAPI 保护。云端备份不包含平台 Cookie。

数据访问与清理

视频、LLM Key 和 Cookie 按敏感数据管理，使用最小权限、磁盘加密和受控备份。

不要将 data、助手目录、Cookie、runtime、日志或 .env 提交到代码仓库。

云端视频没有应用层端到端加密；HTTP 直连限制网络访问范围。

删除云端用户不会自动擦除离线电脑的助手数据。在线时可创建删除本地账号任务，或通过终端管理策略清理。

商品链接读取限制内网和保留地址；携带 API Key 的请求不自动跟随重定向。

附录 B 备份与保留策略

备份和恢复

1. 至少每日备份完整 MPAU_DATA_DIR。一致性要求高时，先停止 FastAPI。

2. 恢复 auth.db、任务状态、素材和 LLM 凭据，并恢复目录权限。

3. 仅启动一个 FastAPI 进程，检查 /api/readiness、任务列表和结果待核对记录。

4. 需要更换执行电脑时重新配对并登录平台；平台 Cookie 不在云端备份内。
