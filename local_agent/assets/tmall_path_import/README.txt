天猫视频/图文路径导入工具（Windows / WPS）

使用条件
- Windows 10 或 Windows 11。
- 不需要安装 Microsoft Excel。
- 生成的 .xlsx 文件可以使用 WPS Office 打开。

使用方法
1. 先完整解压 ZIP 压缩包，不要直接在压缩包预览窗口中运行。
2. 双击 Run_TmallVideoPathImport.bat。
3. 第一个窗口先选择模板，脚本会自动识别视频模板或图文模板。
4. 视频模板：选择视频文件夹；随后可以选择是否导入封面。
5. 图文模板：选择总图片文件夹，脚本会读取其下一级子文件夹的绝对路径。
6. 最后选择生成文件的保存位置。

匹配规则
- 视频绝对路径写入 A 列。
- 封面绝对路径写入 B 列。
- 按不含扩展名的文件名匹配，不区分大小写，并自动处理全角/半角字符及首尾空格差异。
- 例如：001.mp4 会匹配 001.jpg 或 001.png。
- 没有匹配到封面的情况下，B 列保持空白。
- 自动扫描所选视频和封面文件夹及其子文件夹。
- 封面不限制扩展名；只要主文件名与视频一致就会写入 B 列。
- 视频模板可以跳过封面导入，跳过后 B 列保持空白。
- 图文模板会将总文件夹下的第一级子文件夹按名称排序，并将每个子文件夹的绝对路径逐行写入 A 列“图片文件夹路径”。
- 图文模板不会读取子文件夹里面的图片文件名；平台任务会自行读取每个文件夹内的全部图片。
- 支持局域网公盘的映射盘符和 UNC 路径，例如 \\192.168.1.10\share\videos，前提是当前 Windows 账号有访问权限。
- 每次最多处理 200 个文件，与模板预留行数一致。

如果 BAT 文件仍无法启动
请右键 Run_TmallVideoPathImport.bat，选择“以管理员身份运行”；
或者在解压后的文件夹中打开 Windows PowerShell，执行：

powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\TmallVideoPathImport.ps1
