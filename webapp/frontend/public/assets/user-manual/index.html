日常发布操作速查

适用于已经安装并配对 Windows 助手的用户。首次使用请先完成第 1 章，再按本页操作。

1. 打开发布台和 Windows 助手，确认网页显示代理在线。

2. 进入“发布工作台”或“批量发布任务”，选择平台、内容类型和店铺，点击“校验 Cookie”；失败时先重新登录。

3. 选择素材并填写内容。核对图片顺序、封面比例、标题、商品 ID、声明和定时；批量素材必须在执行电脑上可读取。

4. 首次使用或更换关键配置时，先创建流程验证任务。在“任务与日志”确认验证完成，检查 Edge 中的素材和字段。

5. 准备正式提交时，取消勾选“流程验证”，重新创建正式发布任务。批量任务也要明确选择正式发布。

6. 保持助手和 Edge 运行，查看任务结果。平台接收后，再到平台后台核对审核、定时和上线状态。

提交前再检查一次

平台、店铺和素材是否正是本次要发布的内容。

工作台是否沿用了上次的字段或发布时间。定时至少比提交时晚 2 小时。

同一内容是否已经提交，历史任务是否还有“结果待核对”。

看到异常时

失败：先查看任务错误，再修正原因。批次部分失败见第 11 章；修改 Excel 后需重新上传，重执行不会读取新表格。

结果待核对 先查平台后台。确认是否已经提交之前，不要重复创建相同内容的任务。

流程验证 验证会上传并填写页面，但不执行最终发布。验证任务完成后，还需要另建正式发布任务。

第 1 章 首次使用

1.1 登录发布台

准备一台安装 Microsoft Edge 的 Windows 电脑、你的系统账号及平台登录方式。网页负责填写任务，Windows 助手负责执行，Edge 用于平台登录与人工验证。

1.1.1 已有账号

打开发布台，在“登录”页输入用户名和密码。管理员使用已有管理员账号登录，无需重新注册。

1.1.2 没有账号

1. 切换到“注册”，填写用户名；显示名称可按需要填写。

2. 在“所属品牌”下拉框选择公司已登记的正确品牌；注册后可访问所选品牌的数据。品牌缺失时联系管理员，不能通过手输相似名称替代。

3. 设置至少 10 个字符的密码，填写“确认密码”，点击“注册并进入发布台”。注册成功后获得操作员权限。

当前自助注册按选择的品牌授予数据访问，不验证真实任职归属，适用于公司可信内部人员。管理员应核对账号的品牌选择。

第 2 章 登录目标平台账号

系统账号用于进入发布台；平台账号用于登录天猫、京东、小红书或抖音。完成系统登录后，仍需在本机 Edge 中登录目标平台。

1. 进入“发布工作台”，选择目标平台和发布类型。

2. 填写或选择“店铺”标识。它用于区分本机保存的平台账号，例如 店铺A 或 shop_a，不要求与真实店铺名相同。允许中文、字母、数字、下划线和连字符，长度 1–64；同一账号保持使用同一标识。

3. 点击“登录 / 重新登录”。本地助手会打开 Edge；若窗口未显示在前台，点击 Windows 任务栏中闪烁的 Edge 图标。

4. 在 Edge 中完成扫码、密码、短信或验证码验证。请确认登录的是目标平台账号。

5. 等登录任务结束，再回到发布台点击“校验 Cookie”。Cookie 是本机保存的登录凭据；校验用于检查登录是否仍有效。

校验失败 先重新登录并完成平台验证，再校验。登录、人工验证和平台 Cookie 均在执行任务的用户电脑上处理。

第 3 章 单条发布与素材

3.1 发布一条视频

入口为“发布工作台”。开始前确认助手在线、目标店铺 Cookie 校验通过，并准备好可读取的视频文件。

1. 选择平台、“视频发布”和店铺。切换后再次确认目标账号。

2. 点击“选择视频文件”，或通过 DAM 选择视频。支持 MP4、MOV、MKV、M4V、AVI、WebM。

3. 需要自定义封面时选择封面图片。天猫有自定义封面时必须明确选择“原始”“3:4”或“1:1”；无自定义封面时无需设置比例。京东封面只支持 JPG/PNG，最大 5 MiB。

4. 填写标题，以及当前平台显示的文案、标签、商品 ID、话题、音乐和创作者声明。京东视频没有独立正文，不要在文案字段填内容。平台限制见第 4 章。

5. 需要定时时选择发布时间，至少比当前时间晚 2 小时。不需要定时则留空。

6. 首次使用或修改了平台、封面、字段时，勾选“流程验证”，点击“创建流程验证任务”。

7. 到“任务与日志”查看任务消息和 Edge 页面。确认填写正确，并看到“流程验证已完成，未提交发布”后，回到工作台复核配置。

8. 取消勾选“流程验证”，点击“创建正式发布任务”。执行期间保持 Edge 和助手运行，结束后查看结果。

3.1.1 如何判断完成

流程验证的“已完成”只表示测试结束。正式任务提示“平台已确认接收发布”表示平台接收了提交；是否审核通过或按时上线，还需查看平台后台。

3.1.2 素材与草稿

浏览器只保留不超过 100 MiB 的视频草稿副本。更大的视频仍可发布，但刷新页面后需重新选择。普通文件选择使用本机助手接收素材，实际文件大小还受助手和平台校验限制。

再次发布前 工作台可能保留上次的配置。再次提交前逐项检查素材、店铺和发布时间，避免沿用旧配置。

3.2 发布一条图文

图文沿用视频的账号登录、流程验证和正式发布步骤；素材准备方式如下。

1. 在“发布工作台”选择平台、“图文发布”和店铺。

2. 点击“选择图片文件”按顺序选择，或点击“选择图片文件夹”。文件夹模式只读取第一层支持格式图片，按文件名排序。

3. 检查页面图片清单。用“上移”“下移”“移除”调整顺序；确认第一张及后续图片符合内容安排。

4. 天猫图文必须选择图片比例：“原始”“3:4”或“1:1”。原始比例跳过裁剪；另两种比例会进入裁剪流程。

5. 填写标题和当前平台支持的正文及其他字段。先创建流程验证任务，检查图片顺序和裁剪结果，再创建正式发布任务。

第 8 章 修改候选并导入发布台

8.1 手动编辑或 AI 改稿

1. 在候选卡片分别选用一条标题和一条正文。标题与正文可来自不同序号，导入前检查两者是否相互匹配。

2. 少量修改可点击对应卡片的编辑按钮，保存后再复制或导入。保存编辑不会自动成为选用样本。

3. 批量修改时，在候选区“AI 改稿”选择“全部标题和正文”“全部标题”或“全部正文”，填写“修改要求”，核对将修改的条数，点击“批量修改”。

4. 等待改稿完成，再核对每条候选并重新选择。候选数量保持不变；改稿失败时保留整组现稿，按错误提示修正要求后重试。

修改要求示例：语气更自然，减少夸张表达；正文先写使用场景，再写已经确认的卖点，保留各条差异。不要要求模型补造商品事实。

8.2 导入发布台

1. 检查候选区底部的已选标题、正文序号，点击“导入发布台”，选择目标平台和视频或图文。

2. 回到“发布工作台”检查导入文字，再选择素材、店铺、商品 ID、声明和定时等字段。京东视频只导入标题。

3. 按第 3 章先做流程验证，再创建正式发布任务。仅导入文案不会创建或提交发布任务。

8.3 选用样本何时记录

实际填入发布台成功后，系统自动把本次导入的字段保存为品牌选用样本，并冻结导入时的版本。京东视频只记录标题。后续修改原稿或发布台，不会改变该样本快照。

生成、复制、保存编辑或导入批量 Excel 都不会自动计为选用。同一版本、相同候选的重复导入不会重复累计，重复导入也不会自动恢复已撤回的样本。

若提示“文案已导入发布台，但品牌样本未保存”，文字仍已填入。按发布台的提示重试保存样本；无需重复创建发布任务。样本文字不合格时，按错误修正后再导入。

第 9 章 维护品牌写作画像

入口为“AI 文案工坊 → 选择文案品牌 → 品牌画像”。画像展示当前品牌的已确认偏好、待确认偏好、选用样本和最近文案。

9.1 确认写作偏好

1. 完成改稿并导入发布台后，打开“品牌画像”检查待确认偏好。分析未完成时，可在相应选用样本点击“分析偏好候选”。

2. 阅读候选内容、来源和适用范围，必要时先编辑候选。系统一次最多提出三条偏好候选，候选在确认前不参与后续生成。

3. 默认适用于来源文案的场景与风格。只有确实需要通用时，才勾选“适用于本品牌所有场景与风格”。

4. 点击“确认为品牌偏好”使其生效；不合适的候选点击“忽略”。已有同范围的冲突偏好时，先检查旧规则，不能假定新规则会自动覆盖。

9.2 停用偏好与撤回样本

不再适用的已确认规则可点击“停用偏好”。在“选用样本”中，样本创建者或管理员可以点击“撤回样本及其偏好”，同时停用该样本关联的候选和生效偏好。

点击“恢复样本”只恢复样本，不会自动恢复相关偏好。恢复后应重新检查画像中的规则状态；需要管理员协助时提供品牌名与样本内容。

9.3 继续编辑历史文案

展开“最近文案”，自己的记录可以点击“继续编辑”，恢复候选后继续改稿或导入。其他用户的记录用于共享查看，不能通过该入口继续编辑他人的文案。

偏好分析失败不影响已保存的样本，可稍后重试。未修改的初稿直接导入也会记录为正样本，但不会仅凭该初稿自动推断长期偏好。

这项学习使用样本和明确规则补充后续生成上下文，不训练模型参数。旧样本仅供表达参考，不能当作当前商品事实。导入表示选用，不代表已经发布。

11.1.1 结果待核对的处理顺序

1. 记录任务的平台、店铺、标题、创建时间和素材。

2. 用同一平台账号进入后台，按对应内容和时间查找，确认是否已提交、待审核、定时或已发布。

3. 找到内容后，按后台实际状态处理，避免重复创建。未找到时继续结合任务日志核对；确认没有提交后再决定重建。

11.1.2 取消和删除

排队任务可以取消。执行中的任务取消后先进入“正在中断”；如果平台提交动作已发生而回传中断，可能转为“结果待核对”。取消不等于撤回已经发布的平台内容。

删除终态任务前先保留需要的错误信息。删除只移除任务记录和独立日志，不删除平台内容、Cookie 或平台总日志。顶部“需处理”同时包含失败和结果待核对，不能只看统计数字判断结果。

11.2 处理批次中部分失败的任务

批次中一条任务失败，不会阻止后续任务执行。先查看失败条目的 Excel 行号、错误消息和日志，再决定使用重执行还是重新创建任务。

11.2.1 原有内容无需修改时

1. 在“任务与日志”找到对应批次，先核对成功、失败和结果待核对的条目。

2. 修正错误原因，例如重新登录并校验 Cookie、恢复网络，或将素材恢复到原路径。

3. 点击批次的“重执行失败项”，或详情中的“一键重新执行失败任务”，确认后查看新建任务。该操作只重建失败条目。

4. 查看新任务结果。若原任务是流程验证，重执行后仍然是流程验证；要正式发布必须另建正式任务。

11.2.2 需要修改标题 文案 路径或定时时

修改 Excel 后，重执行按钮仍使用原任务保存的参数，不会读取修改后的表格。请把需要修改且确认未提交的内容整理成新表，复核后重新上传创建任务。

避免整批重复提交 已成功的条目不要再次放入新表。使用行号与标题逐条核对需要重建的内容，保留原批次以便追踪。

11.2.3 结果待核对先查平台

“结果待核对”不属于失败重执行范围。用同一平台账号到后台确认是否已经提交；确认前不要重建。取消任务也不等于撤回平台内容。

需要管理员协助 提供批次或任务编号、Excel 行号、平台、店铺和错误消息，便于定位；不要发送密码、API Key 或完整 Cookie。

14.2.2 分类机会图

“规模与点击效率”气泡图的横轴是曝光占比，纵轴是商品点击人数除以曝光人数，气泡大小表示单篇曝光。虚线用于对照当前范围的平均点击率与平均曝光份额。

贡献图使用当前选择的指标计算占比，先确认指标名称，再判断哪个分类贡献较大。前五篇贡献集中度越高，说明所选指标更集中于少数作品；它本身不能证明内容策略有效或无效。

“子分类总结”在数据更新后自动重算，查看优势、不足和建议。提示暂不可用时检查 LLM 适配器；分类样本少、分母小或数据缺失时，应结合原始数据谨慎判断。

14.2.3 生成本周期分析

1. 在当前账户“LLM 适配器”验证并启用模型，返回看板选定下载周期。

2. 在“本周期五维分析”点击“生成 AI 分析”。未点击时页面显示规则分析，并明确标识未调用 AI 模型。

3. 查看分析结论并展开“查看数据依据”，区分数据观察、待验证假设和建议；需要追问时点击“打开对话助手”。

每次生成或重新分析都会调用模型。失败时保留现有分析，按提示重试；切换周期会清除旧 AI 结果，应针对新周期重新生成。AI 的归因解释需要进一步验证。

15.2.3 维护后的行为

手动维护的条目会受到保护，自动提取不会覆盖。编辑、撤销或恢复会取消该品牌尚未完成的旧提取任务；需要保留的未处理信息应在后续对话中重新明确提供。

出现版本冲突时刷新后重试。提取失败可点击“重试更新”；管理员关闭长期记忆时，仍能查看和维护已有记录，但新对话不会自动整理或注入这些记忆。
