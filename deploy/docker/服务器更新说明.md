# 175.27.255.46 服务器更新

本包为源码部署包，服务器需安装 Docker Engine（支持 host-gateway）及 Docker Compose 插件，并可访问构建所需的镜像和依赖仓库。服务运行在 Docker；MySQL 直接运行在服务器宿主机。

## 更新已有服务

1. 在服务器备份原项目目录、`deploy/docker/docker.env` 和数据库。记录原 Compose 配置中的数据卷及安装包挂载路径。
2. 将压缩包解压到原项目根目录，覆盖源码文件。包内没有真实 `docker.env`，不会覆盖原环境配置。
3. 编辑原 `deploy/docker/docker.env`，设置 `MPAU_MYSQL_HOST=host.docker.internal`，填写实际端口、数据库名、账号和密码。示例端口为 3306，不要直接沿用本机 SSH 转发端口 13306。其他服务配置和 AI 模型凭证继续使用服务器原配置。
4. 在项目根目录运行：

```bash
bash deploy/docker/update-server.sh
```

脚本会检查必填数据库配置、构建并更新容器、验证 MySQL 连接。连接失败时会以非零状态退出，但已更新的容器会保留，供检查日志和修正配置。脚本不会执行数据导入、数据库迁移或删除数据卷。

默认使用现有 `mpau-data` 命名卷；若服务器自定义了 Compose 或数据卷，请将本包配置与现有配置合并后再更新。MySQL 必须允许容器通过宿主机网关访问，应用账号也需允许 Docker 网络来源；MySQL 仅监听 127.0.0.1 时不能连接。无需开放公网 3306。

## 首次部署

运行脚本将生成权限受限的 `docker.env` 并退出。填写数据库连接配置，按需设置其他服务参数，然后再次运行脚本。既有服务更新不要重新初始化管理员。

## 查看日志

```bash
docker compose -f deploy/docker/docker-compose.yml logs --tail=100 mpau-web
```

本包包含最新五维定制分析、宿主机数据库网关配置及锁定的 MySQL/RSA 认证依赖。没有包含本机凭证、数据库、业务数据、虚拟环境和 node_modules；前端将在 Docker 构建时生成。包内不包含 Windows 助手安装程序，服务器原 `deploy/windows/output` 文件请保留。
